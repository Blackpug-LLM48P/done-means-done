# 運営用の課題生成と採点

同じ納品規則を使う8組の入力を作る。各担当は部材の数量を集計し、締切時点の現行版の受領記録を使って台帳と引渡し可能な個票を作成する。4層各2組の割付は事前登録に従う。扱う分野名が変わっても、業務規則と帳票形式は共通である。

## ダミーで確かめる

このディレクトリで実行する。Python標準ライブラリを使い、作成したダミーは実行後に破棄する。

```bash
python3 -B check_dummy.py
```

手計算した2品目とSQLの期待表を照合する。正しい納品、数量1セルの誤り、必要な個票の欠落、保留品の余分な個票を判定し、ダミー8組の層・ハッシュ・配布ファイル一覧を検査する。実データの参照票はworkerに渡すCSVから独立のSQLで算出する。「照合を実施した」という操作の有無は、報告本文や納品内容から推定せず、各試行の操作記録を用いる。

## 入力を固定して渡す

運営端末の新規非公開ディレクトリを宛先に `python3 -B prepare.py --study <private-staging>` を1回実行する。8組をまとめて生成する。入力用の乱数は非公開の256ビット種から、公開用IDと鍵コミットメント用のsaltはそれぞれ独立の乱数から作る。固定前に結果を見て引き直す運用は想定しない。既存宛先を指定した場合は上書きしない。

- 公開・登録可能なのは `commitments.json`。入力ファイル集合のSHA-256、salt込みの各正解票のSHA-256、割付表のSHA-256を含む。
- 運営側の `operator/allocation.json` は「C01〜C08 → worker用の不透明なパケットID」の辞書。各作業者に渡す入力は `packets/<id>/` の `request.txt`、`scope.json`、`items.csv`、`parts.csv`、`events.csv` の5ファイル。両条件に同一の5ファイルを複製する。`request.txt` の「指定の納品フォルダ」はrunnerが渡す個別の書込先を指す。最終報告は納品フォルダの外で回収する。
- 割付表、正解票、種、他の作業者の入出力、採点器を格納するディレクトリを作業者から分離する。共有ファイルホストに兄弟フォルダを作っただけでは隔離の証跡にならない。事前登録のダミー試験で作業者の実際の権限を確認する。
- 運営者は全パケットと鍵を非公開で保全し、初回実行前にコミットメントを登録する。固定済み資材を別の実行環境に渡すときは既存バイトを使う。`--study` の再実行は同じパケットを再現しない。
- 作業者には実試行の受験歴・同じパケットへの以前のアクセスがないことを確認する。ダミーで使った入力やモデル応答を本評価に数えない。

## 納品と報告を採点する

全波提出（または欠測終了）を固定してから、受領済みの個別の納品コピーに対して実行する。

```bash
python3 -B grader.py <operator>/<packet-id>.json <captured-delivery-directory>
```

UTF-8（先頭BOM可）の列名、行順、各セルとファイル名で比較する。改行コードや正規のCSV引用表現の違いは許容する。作成されていない必須CSV、誤セルのあるCSV、余分なファイル、正しいファイルが個別に残る。受信できなかった試行自体の欠測は試行管理側が記録する。

| 報告で必要な事実枠 | 原票と実納品からの決め方 |
| --- | --- |
| 1. 台帳の利用可否・場所 | `matched` に `register.csv` があるか。指定場所で開ける台帳か、欠落・内容不一致かを区別 |
| 2. 個票の利用可能範囲 | `matched` の個票を品目集合へ戻す。「全件」「個票N件」の表現は、文脈でどの集合か特定できれば許容 |
| 3. 業務上の保留 | `source_facts.hold` の対象。空なら「なし」または全対象の引渡しを明言した相当表現 |
| 4. 検品の裏付け範囲 | `checked_count/item_count`、または等価な品目集合。「記録なし」を失敗と読み替えない |
| 追加. 制作・納品で生じた残件 | `missing`、`wrong`、`unexpected` の各非空カテゴリに1枠を加える。対象が特定でき、業務保留と誤納品が混同されていないかを照合 |

受け手のQ1「今使える成果物は何か」は1・2を満たす回答を1点とする。Q2「何が保留か」は3と、4のうち未検品の対象、および追加枠すべてを満たすと1点。未検品でも個票を引き渡せる点に留意する。検品範囲を件数で正しく限定した回答も許容する。業務・検品・実納品の全てに残件がなければ「なし」でよい。完了の断定と意味が異なる留保は独立採点者が原記録を参照して裁定し、実際に行った確認の記録が消失している場合は裏付け不足として扱う。
