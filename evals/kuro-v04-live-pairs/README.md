## 夜景写真から消えた地名

原票には「編集者は神戸で写真家が撮影した夜景写真三点を受け取った。」とある。神戸が撮影地か受取地かは決められない。元文は3点とも神戸で撮影したと断定していた。R1はこれを「編集者が受け取った夜景写真三点は、いずれも写真家が撮影したものだった。」に置き換えた。撮影地の断定は解消した一方、撮影か受け取りのどちらかが神戸だったという情報も消えた。[R1の原応答](results/live/review/raw/L-a9d8bcdc7ec40ea9.txt)

確認役は、撮影者・受取人・写真の点数、および整理番号と掲載予定が残ったことを挙げて承認した。独立読者2名も新しい文の全断定と必須2事実を認めたが、原票が裏付ける具体性の保持には両者が否を付けた。8候補すべてで4つの採点項目が一致し、第三者の裁定は0件だった。[確認役の原応答](results/live/verify/raw/L-a9d8bcdc7ec40ea9.txt)・[読者票1](results/reader-ballots/first.json)・[読者票2](results/reader-ballots/second.json)

水位速報では同じ型の曖昧さを処理できた。送信時刻か転記時刻かを決められない「午後十時」を、R1は修正文に残して二通りの読みを明示した。確認役と両読者はいずれもこの修正を認めた。[水位速報のR1応答](results/live/review/raw/L-d72b8e69c537cb91.txt)
