# 版と作業を照合する根拠行検索

この評価器は、案件内の版付き完了主張について、候補となる直接記録を1行選ぶ。保留は JSON の `null` で返す。直接性は入力された行単位の出所区分に依存する。

## 実行

Python 3 の標準ライブラリを使用する。以下はこのディレクトリからの実行例。

```sh
python3 -B dev_selftest.py
python3 -B scope_matcher.py cases.json --output predictions.json
sha256sum -c freeze.sha256
```

入力は1案件のオブジェクト、その配列、または配列を `cases` に格納したオブジェクト。複数ファイルも受け付ける。IDF と平均行長は1回の呼び出しに含めた全案件の根拠行から計算する。比較したい案件を一緒に渡す。

```json
{
  "case_id": "dev-example",
  "rows": [{"id": "e", "text": "r9 見本を受領した", "source": "direct"}],
  "queries": [{"id": "q", "question": "見本 r9 は届いたか", "claim": "r9 見本を受領した"}]
}
```

各案件内で根拠行のIDと質問のIDはそれぞれ一意。出所は `direct`、`reported`、`hearsay`、`inference` のいずれか。検索と照合には質問文・主張文・行原文を使用し、出所はゲートでのみ参照する。

## 比較条件

全条件で公開済みの前回比較と同じ字句抽出・BM25の式を使う。NFKC正規化と小文字化後、ASCII英数字ランは1語、日本語ランは文字2-gram、1文字のランは1語。質問・主張で出現する特徴の和集合について、k1=1.2、b=0.75、IDF=log(1+(N−df+0.5)/(df+0.5)) で加算する。候補は同一案件の正の得点を持つ行。同点は原文順を保つ。行・質問のIDは語彙や順位に使わない。

| 条件 | 候補行に課す条件 |
| --- | --- |
| `source` | 出所が直接 |
| `source_revision` | 直接かつ版が一致 |
| `source_action` | 直接かつ作業が一致 |
| `source_revision_action` | 直接かつ版・作業がともに一致 |

`veto` は字句順位1位にだけ条件を適用する。`rescue` は条件に通る候補のうち元のBM25得点が最高の行を採る。同じ語彙統計と得点のまま候補を絞って再順位付けする。

## 照合の範囲

- 版は質問と主張に現れる版の集合と、各行に現れる版の集合から別個に抽出する。双方が1種類ずつで一致した場合に通す。`r`/`rev`/`revision` と `v`/`ver`/`version` をそれぞれ同一表記とし、数字付きの「第3版」等は `v3` として扱う。版が欠ける行、複数版を含む行は版条件で保留する。明示した版にはピリオド区切りの番号も使える。
- 作業は主張文から抽出し、行では肯定的な実施表現を求める。主張に認識可能な実施表現がない場合は、名詞で示された要求作業を拾う。質問に含まれる別作業は要求に加えない。作業の種類はファイルを開く・閲覧する、読める、表示する、照合・校正する、受領・受信する、送信する、テストを実行する、テストを列挙する、保存・書き込む。複数の認識済み作業を求める場合はすべてを満たす同一行が必要。
- 「目視」等を伴う照合は行にも目視等を示す語を、「全ページ」等の明示は行にも対応する全範囲表現を求める。行の1つの節に必要な限定がそろう必要がある。件数そのものの一致は判定しない。テスト実行の成功も述べた主張には合格・通過等の表現を求める。
- 句読点で節を区切り、同一節の代表的な否定、予定、未実施、失敗等を抑止する。テスト収集だけのオプションや実行0件等は実行扱いを抑止する。文法解析、共参照解決、引用の出所推定、別文にまたがる否定や限定の結合は行わない。語彙外の述語、複数作業の係り受け、結果未記載のログ見出しなどは誤判定や保留を生じ得る。
- 案件内で対象物と送受信先が一意に決まる制御文を想定する。同じ版番号で複数の対象物や宛先が混在する記録、時刻・数量・照合対象フィールド、入れ子の引用を識別する照合器ではない。判定は候補行の提示に限定し、作業の完了認定や現行の判断規則を変更しない。

## 出力

`cases[].rows[]` に行ごとの出所、抽出版、作業・限定語。`cases[].queries[]` に質問ID、抽出した要求、全8条件の結果を格納する。`arms[条件][方針]` の `row_id` は選定した行IDまたは `null`、`reason` は選定・保留の理由、`top_lexical_id` は素のBM25の首位、`scores` には候補外の0点行も含め、全行のBM25得点とその条件の照合結果を保存する。元の評価用正解は読まない。

固定対象は評価器、この文書、独自に書いた開発用自己テスト。前回の公開済み評価器・規約・公開例を参照した。新しい評価ケースおよび採点用の正解にはアクセスせず、開発用の例だけで自己テストを実行して固定した。
