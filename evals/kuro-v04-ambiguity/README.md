### 読者が割れた2件

元文・R0候補・R1候補の123枠を、同じ原票・本文ごとにまとめた72件について、それぞれ独立に2票を得た。中断前に保存された1組24件の読者票を引き継ぎ、残る5組120件を再開後に採点した。70件では必須事項と未裏付けの文番号が一致した。第三者には不一致の2件の原票・本文だけを渡し、事前登録どおり該当文を裁定した。

いずれもR0の「別館で展示台を組み立てた職人の姿をカメラに収めました」。1件は組み立て場所が明示され、もう1件では原票にも同じ曖昧さがある。どちらも第三者は不合格とした。特に後者では、元の曖昧さを保存した表現をそのまま許容する読み手もいた。この2件で許容票を採ればR0の修正合格は35本から37本になる。これは事後の感度確認で、固定した成績と採否には裁定票を使った。採否対象40本の元文では、匿名票と作問時の指摘対象文が全件一致した。
