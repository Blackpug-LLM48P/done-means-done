## 修正した主要な機構

| 対象 | 修正前の観測 | 修正後 |
| --- | --- | --- |
| 未知の引用ID | 存在しないL99でも全体一致へ落ちて0 | UNKNOWN ID、1 |
| 未知のdraft ID | `--draft L99`で自己引用チェックが無効のまま0 | INPUT ERROR、2 |
| 引用・表の読み落とし | 有効引用の後の未閉鎖引用、先頭パイプなし行、余剰列を読み飛ばして0 | 構文問題を記録して1、または対象行を実際に照合 |
| 引用内ID | 引用文中のL02を次の引用元にし、見逃し・誤警報 | 引用内文字列をID抽出から除外 |
| draft-only判定 | 別の非構造化ファイルだけにある引用をDRAFT ONLYと誤判定 | 前置き・非構造化記録も非draft証拠に含め、draft内の実在も条件にする |
| 複数記録の同名ID | ファイルをまたいで同名IDを合成 | 曖昧な入力として2。ファイル別に検査する契約 |
| 壊れた範囲・桁表記 | 逆順/別接頭辞を短縮、L01-L2をL01-L02に改変 | INVALID ID、1。存在と表記を保持 |
| 自己引用 | draftを明示的に引用しても他所に同じ語句があれば通過し得る | 明示draft引用とdraft-onlyを区別して失敗 |
| 他の表 | 本文セルのEvidenceを台帳ヘッダーと誤認 | 表の状態を保持し、ヘッダーの列で判定 |
| 文字・エスケープ | 補助漢字40文字が通過、ASCII引用のエスケープ解釈が曖昧 | 補助漢字も字数制限。ASCII引用の二重引用符・バックスラッシュの復号を明文化 |
| 検査範囲 | ID照合と記録全体一致を同じ成功表示 | ブロック一致数・全体一致のみの数・draft検査の指定有無を表示 |

元の42テストには「未知IDならFOUND」を期待するテストがあった。その期待値は修正方針とともに変更した。既存の悪い仕様を維持してテストを緑にしたわけではない。新しいCLI境界テストを旧実装へ適用すると失敗することも `counterfactual.json` に記録した（サブテスト失敗件数はバグ件数ではない）。

## 採点基準とスキル入力

- **BOM**：書込み要求＋成功応答、指示適合性、実バイトの再読取を分離。全数値指標から除外して定性的な記録だけに統一。「設定変更による競合解消」を証拠なしに正解とはしない。
- **採点単位**：元の誤主張、新規の根拠不足な主張、誤った否定、範囲拡張を区別。クリーンログのK5/K6を説明項目と二重計上しない。単なる省略は保持率低下として扱う。
- **相関**：行数の誤報告と未処理項目の欠落などは関連する指標であり、合計して独立した失敗数にしない。
- **測定履歴**：「未測定」と過去のpilot結果を混同しない。「外部評価が最も信頼できる」「ヘッダーが下流の安全性を保証する」とは主張しない。DESIGNの(a)を実際の点検依頼つきベースラインへ合わせた。
- **3規則**：発言と事実の分離、draft自己根拠禁止、新規の根拠不足主張禁止は未評価提案へ移した。機械的なdraft検査の修正は、それらのモデル向け介入の有効性を意味しない。
- **例題**：引用の文字列一致を検出するテストは登録済み2記録だけを対象とする。題材を変えても誤りの構造は似ており、このテストは意味上の独立性や未見性を証明しない。

採点基準の再レビューは阻害する矛盾なしとの結果。ただし採点者間一致率を測ったものでも、6出力を改訂3で再採点したものでもない。

## 残る制約・未実施

- 未引用の文章、意味的な支持、全主張の抽出、下流の実行、記録の真正性は検査対象外。対応外の任意の引用記法をすべて検出できるとは言わない。パス・時刻を引用先へ解決する機能はない。
- 複数ファイルはIDが全体で一意である場合のみ扱う。ファイルローカルIDを持つ複数記録の名前空間指定は実装しない。完全なMarkdownパーサでもない。
- 既存Step 1の「失敗をREMAININGへ追加」という広い文言と、復旧済み経緯の区別には挙動上の課題がある。新たな介入を混ぜないため、この点は提案ファイルに明記して今回の実行用スキルでは変更しない。
- 新規ログ、(c)の実作業者試験、Opus比較、複数反復、トークン/費用比較、下流挙動、B3実験、CIサービス上の実行は未実施。
- 旧キー・旧Claude出力・原記録・origin・研究追補は履歴として保存。研究追補の外部論文の内容・リンクの現在の有効性は再検証しない。
