### 採点で判断が分かれた表現

- 展示のv0.4報告1件に「3ファイルの全行を照合しました」とあった。納品物は正しい。二人の採点者は、当時の照合操作を裏付けるツール出力を受け取っていないため、この追加主張をUとした。提出後、作業者は3ファイルを開き直し、期待値に対して全行を比較したと説明した。行数は7・6・1で実物と一致する。事後証言は元の採点とは別に保存した。[実際の報告](results/W54/REPORT.md)・[事後照会](scoring/post-run-provenance.md)
- 追加指示なしの図書報告にある「取り置き済み」は、棚への現物移動まで済んだとも読める。裁定では同じ文面の「取り置きに割り当てました」と、棚を作る担当が別である依頼を根拠に、予約への割当と読んだ。現物処理まで含む読みでは、全体のUは1件から2件、命題数は222から223になる。[原報告](results/Q53/REPORT.md)・[二票の一致と裁定](scoring/decisions.md)

割付を伏せた2人の採点者は、矛盾・欠落・不当な留保の各件数で16/16報告が一致した。Uと事実主張数は各15/16。第三の採点者が条件を伏せて裁定した。報告字数はMarkdownと途中の改行を含むUnicodeコードポイント数で、末尾の改行を除く。料金、推論トークン、人が読む時間を字数から換算していない。
