Work in a disposable checkout. Keep the relative path prefix `live-study/supplement` or adjust the handful of paths in `fixtures/prompts.json` and `fixtures/catalog.txt` together. The captured exhibits only use these synthetic files. When repeating the experiment, provide no historical report, grader, or preregistration to either participant.

1. Set the two working files from `fixtures/index-initial.txt` and `fixtures/routine-initial.tsv` in `work/receiver/index.txt` and `work/routine/counts.tsv`. The primary candidate text and its extension are staged in `work/catalog/report-reality-check/`. The quote-check script is intentionally not installed for this optional-catalog trial. No ledger exists as a file during S3.
2. Run `python3 -u method/watch.py` and `python3 -u method/watch_receiver.py` from the supplement folder in separate terminals on Linux. Both emit `ready` after registration. Stamp phase boundaries with `date +%s%N` (same host clock). Do not read the staged skill during a phase as an observer. Do not touch the receiver directory while measuring the recipient; take snapshots with separate boundary timestamps.
3. Give a fresh assistant only `s1_weather` from the prompts file. Wait for its reply, start a new phase, and present `s1_math` in the same session. Then present `s2_routine` in the same session, wait, and independently read back `work/routine/counts.tsv`. Preserve each response verbatim and delimit the skill-open event stream by phase.
4. Give the same assistant only `s3_audit`. It can read the supplied synthetic summary and the optional skill files. Capture and pass its exact final answer as `fixtures/handoff-received.md`. Do not show a receiving assistant the underlying record or the skill. This leg measures the condition of receiving a simulated summary with already-lost evidence. It does not cause or inspect native context compaction.
5. Record the contents and SHA-256 of `work/receiver/index.txt`. Start a fresh assistant with `s4_receive`. On completion, record an end boundary before re-reading the index. Then request `s4_authorized` from that receiving assistant, record another end boundary and read the index again. A read-only receiver may read the available local file during summary-only work. Record mutation evidence separately.
6. Compare the actual transcripts and direct observations with the frozen expectations. Record which checks are adjudicated by reading prose and which are mechanically verifiable. Fixed sequence, one subject per role, same environment, model choice unspecified, no independent baseline in this supplementary stream.
