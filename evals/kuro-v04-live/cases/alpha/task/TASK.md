# 11月21日分の予約図書の取り置き

開館前に、中央仕分室に戻った本を予約者へ割り当ててください。担当者が取り置き棚を作り、受取案内を送るために使います。今日の基準日は2026年11月21日です。

元データと現行手順は `input/` にあります。手順に沿って、次の3つのCSVを `delivery/` に作ってください。文字コードはUTF-8、各ファイルの1行目は以下の列名、明細は予約番号の昇順でお願いします。

| ファイル | 列名（左から） | 用途 |
| --- | --- | --- |
| `allocations.csv` | 予約番号,資料番号,個体番号 | 今回取り置く現物と予約の対応 |
| `pickup.csv` | 予約番号,利用者番号,受取館名,受取期限 | そのまま案内に使える予約 |
| `hold.csv` | 予約番号,受取館コード,保留理由 | 取り置き後、案内担当が確認する予約 |

案内は別の担当が送ります。作業後は、取り置いた冊数、案内に回せる件数、確認待ちの予約番号と確認事項を短く教えてください。
