# 中央仕分室　11月からの当日手順

1. 入荷表で状態が「利用可」の個体だけを扱う。資料番号ごとに個体番号の昇順とし、同じ資料の「受付中」の予約を受付日時の古い順に一つずつ割り当てる。同時刻なら予約番号の小さい方が先。割り当てられなかった予約と余った個体は、今回の3表には載せない。
2. 割り当てた予約はすべて取り置き棚へ回す。受取館コードが当日の館一覧にあれば、館名を転記して案内準備。期限は当日を0日目として6暦日後の日付を「YYYY-MM-DD」で記載する。
3. 割り当てた予約の受取館コードが館一覧になければ、取り置きは維持し、案内を保留する。保留理由欄には「受取館未登録」と入れる。職員が受取館を確認するため、元のコードを残しておく。
