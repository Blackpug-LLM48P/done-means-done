# 依頼

夜番あての引継ぎを、以下の記録に照らして書き直してください。対象は東・西・南・北の4拠点です。各拠点の配信先一覧で旧ラベル `PILOT` が何件残っているか、4拠点の合計を出せるかを知りたいです。夜番が確認元をたどれる書き方にしてください。この場で使えるのは貼った抜粋だけです。

## 引継ぎ卓の記録

```text
K21 18:00 受付　対象は東・西・南・北。東西は当番室、南北は拠点担当が照合する割当。
K22 18:05 当番室で検索　east.csv data_rows=18 filter=label:PILOT matches=0 status=ok
K23 18:06 当番室で検索　west.csv data_rows=23 filter=label:PILOT matches=0 status=ok
K24 18:09 南担当から当番室へのメッセージ「南は1件残っていました。」添付なし。
K25 18:14 引継ぎ用に書き出し　当番室スレッドと東西の検索記録を収録。北担当の個別スレッドはこの抜粋の収録範囲外。
```

## 夜番へ渡す前の下書き

東西はどちらも0件でした。南担当からは1件との連絡があり、北も0件です。これで4拠点とも照合が済み、旧ラベルの残りは全体で1件と確定しました。
