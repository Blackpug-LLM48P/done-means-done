## 「神戸」の何を照合できたか

原票は「編集者は神戸で写真家が撮影した夜景写真三点を受け取った。」。写真家が神戸で撮ったか、編集者が神戸で受け取ったかは定まらない。R1の修正案は撮影地の断定を外すと同時に「神戸」を削った。旧版は、撮影者・受取人・点数・整理番号・掲載予定が残っていることを理由に承認した。新版は、撮影か受け取りのいずれかが神戸で行われたという情報まで消えたことを理由に保留した。追加した指示にはこの地名も事例も登場しない。[同じ候補に対する旧版の応答](../kuro-v04-live-pairs/results/live/verify/raw/L-a9d8bcdc7ec40ea9.txt)・[新版の応答](results/live/raw/Q-22ec7966f4d374ab--new.txt)

PR #15の12件の経路にこの判断を戻すと、正常な4件は通過、要修正の7件に正しい案を提示、残り1件は人手確認になる。誤提示は1件から0件に減る。保留した「神戸」には代案を生成していないので、正しく自動完結した件数は両方とも11/12件。これは固定したR1出力を使った再集計である。

## 新作で比較した修正

| 原票が示す事実 | 両版が承認した修正 | 両版が保留した修正 |
|---|---|---|
| 受領部署は広報係。個人名は空欄 | 個人名を外し、部署を残す | 受領済みとだけ伝える |
| 正味重量の表示は18.□ kg | 18キロ台とする | 20キロ未満に広げる |
| 午前は6月12日と19日、午後は調整中 | 午前の両日と午後の未確定を伝える | 午前は日程決定とだけ記す |
| 撮影は松江の資料保存室、公開場所は未定 | 撮影場所を残して公開場所を未定とする | 公開場所を訂正する際に撮影場所も削る |

今回の比較では、これまでの確認役も新作で起きた4種類の脱落をすべて検出した。新版を次の評価に用いる候補とし、実運用での無人適用は保留する。新規案件で上積みがあるかを判断するには、旧版と新版で判断が分かれる機会を含む別の実候補が必要になる。[事前登録と採用条件](PROTOCOL.md)

## 手順と再現

PR #15の[独立採点](../kuro-v04-live-pairs/results/events.json)で良否を確定した8候補は、原票・元文・R1生応答を固定した。旧版の8票は当時の記録を再生し、新版だけを今回実行した。新作は独立した作問者2名による4系列で、各系列の同じ元文に「具体性を保つ修正」と「確かな情報まで削る修正」を用意した。この8候補には旧版と新版をそれぞれ新規セッションで実行した。

公式試行に先立ち、[入力・期待票・追加指示](https://github.com/Blackpug-LLM48P/done-means-done/commit/ea454e3ccd5b4aab926cc96ec6ce98baa8e0adc3)を固定し、[事前登録・監査票・採点コード](https://github.com/Blackpug-LLM48P/done-means-done/commit/ee8b6f262362b6fba2c29450894ca951de59a1be)を封印した。新作8候補の匿名監査では独立したAI読者2名の全16票が作者票と一致した。モデルは原票・元文・候補を受け取り、同じ入力で新旧のプロンプトが[追加した1段落](method/variant.py)だけ異なることを実行時と再生時に照合する。DMD v0.4、R1、確認役の応答判定、B1業務ドライランはPR #15と同じ。
